# Сайт: мобильная загрузка, 23.11.2026

## Изменения

Карта синхронизирована с основной новеллой: 36 объектов, 14 библиотек, Охтенка у перевоза, актуальные реальные описания и ссылки из `world_atlas.json`, фантазийные истории и рисунки, пометки на полях. На компьютере карточки оформлены как разворот игрового атласа, на телефоне как одна страница. Иллюстрации имеют варианты 640 и 1280 px.

Описание: «КрасноЦарство.exe» приглашает в параллельную фэнтези-реальность Красногвардейского района Петербурга. Здесь знакомые места и настоящая история обретают другую жизнь: библиотеки становятся узлами миров, а за привычными адресами скрываются магические тайны.

Искин использует позу чтения `iskin_reading.png` и адаптацию эффектов светового поля и перелистывания из `iskin_staging.rpy`. Оригиналы новеллы не изменены. На телефоне закреплена кнопка «Искин в AR». В разделе проводника есть отдельная крупная кнопка. На странице AR сначала загружается лёгкая проекция; просмотр модели запускается по запросу. Восемь кадров перелистывания входят в GLB и USDZ. На Android предусмотрен Scene Viewer, на iOS Quick Look.

После релиза добавлен раздел «Сотрудничество и пресса», пункт «Связь» во всех меню. Используется уже опубликованный адрес библиотеки `brzh@kr-cbs.ru`. Кнопки открывают письмо с темой, ничего автоматически не отправляют. Пресс-релиз обозначен будущим материалом, фиктивного файла нет.

## Проверка публичного сервера

23.11.2026 проверены HTML и JavaScript, указанный в HTML `https://krasnotsarstvo.ru/`. В ответе сервера nginx/1.18.0 для JS отсутствовали `Content-Encoding` и `Cache-Control`, хотя запрос разрешал сжатие. Передано 149 175 байт. Для похожего входного модуля локальная сборка показывает около 49 КБ gzip. ETag и Last-Modified присутствовали.

Один запрос HTML: DNS 0,30 с, соединение 0,49 с, TLS 1,96 с, первый байт 2,15 с. Это наблюдение с одного компьютера, не статистика скорости сервера. Оно не подтверждает перегрузку базами.

Само наличие поддоменов не добавляет их файлы на страницу сайта. Конкуренция возможна, если базы и сайт делят CPU, память, диск или канал одного сервера. Для проверки нужны метрики Timeweb во время замедления: CPU, память, swap, I/O и сеть. Доступа к этим метрикам в работе над сайтом не было.

## Что сделать на Timeweb

1. Подтянуть `main` и выполнить обычную сборку/публикацию `npm ci` и `npm run build`. Сайт обслуживается из `dist` по существующей настройке.
2. Сохранить копию текущего nginx-конфига. В **существующий HTTPS server-блок только krasnotsarstvo.ru** перенести настройки из `deploy/nginx-performance.conf.example`, объединяя совпадающие location-блоки. Не заменять целиком TLS, root, заголовки безопасности и маршруты других сервисов. Пример намеренно не является полным конфигом сервера.
3. Выполнить `sudo nginx -t`. Только после успешной проверки выполнить `sudo systemctl reload nginx`. В этой сессии эти команды на сервере не запускались.
4. Проверить `curl -I --compressed https://krasnotsarstvo.ru/assets/<актуальный-файл.js>`: ожидаются `Content-Encoding: gzip`, `Vary: Accept-Encoding`, длительный `Cache-Control`. Имя JS взять из опубликованного HTML. Для `/index.html` ожидается `Cache-Control: no-cache`, для рисунков `/atlas/` срок 1 час.
5. Проверить MIME-типы моделей: `/ar/iskin-projection-billboard.usdz` должен возвращать `Content-Type: model/vnd.usdz+zip`, GLB `model/gltf-binary`. В примере nginx для них предусмотрены отдельные блоки.
6. Открыть сайт на телефоне без старого кэша, проверить карту, AR и переход к гадалке. Нативное размещение через камеру требует проверки на Android/iPhone; настольная эмуляция ширины телефона его не заменяет.

Источники по настройкам: [gzip в nginx](https://nginx.org/en/docs/http/ngx_http_gzip_module.html), [expires и наследование заголовков nginx](https://nginx.org/en/docs/http/ngx_http_headers_module.html). Подход к отложенной загрузке: [MDN](https://developer.mozilla.org/en-US/docs/Web/Performance/Guides/Lazy_loading), [сторонние скрипты, web.dev](https://web.dev/articles/efficiently-load-third-party-javascript).

Нативный AR-вход: [Google Scene Viewer](https://developers.google.com/ar/develop/scene-viewer), [WebKit Quick Look и MIME-тип USDZ](https://webkit.org/blog/8421/viewing-augmented-reality-assets-in-safari-for-ios/).
